# 2. 외부 서비스 정리

> 프로젝트에서 사용하는 외부 서비스의 가입·활용 정보. (소셜 인증, 클라우드, 코드 컴파일 등)
> ⚠️ 개인키·시크릿은 여기 기재하지 말 것. 주입 위치만 표기.

## 요약

본 프로젝트는 일반적인 소셜 로그인(Google/Kakao/GitHub)이나 Photon 클라우드, 외부 코드 컴파일 서비스를 **사용하지 않는다.** 인증은 **MetaMask 지갑 서명**으로, 결제·정산은 **SSAFY 블록체인 + 스마트 컨트랙트**로 대체된다. 아래가 실제 의존하는 외부 서비스 전부다.

---

## 1) SSAFY 블록체인 (핵심 외부 서비스)

| 항목 | 값 |
|---|---|
| 네트워크명 | SSAFY Blockchain (교육용 프라이빗 체인) |
| RPC URL | `https://rpc.ssafy-blockchain.com` |
| Chain ID | **31221** |
| gasPrice | 0 (무가스) |
| 배포 정보 | `blockchain/deployments/ssafy-31221/deployment.json` |

**배포된 스마트 컨트랙트**
| 컨트랙트 | 주소 | 역할 |
|---|---|---|
| GCoin (GSC 토큰) | `0xaCe3c977A539C16668528619F9417589f12C7B22` | 결제·정산에 쓰는 ERC-20 토큰 |
| GPUJobEscrow | `0x66178DF08F5938d2ABC17496b6A98F7d776D3c56` | 작업 비용 예치·정산·환불 에스크로 |

**활용에 필요한 것**
- 배포/정산용 지갑 개인키: `blockchain/.env`의 `SSAFY_PRIVATE_KEY`, 백엔드 정산 키퍼 `ESCROW_KEEPER_PRIVATE_KEY`.
- 사용자/공급자: **MetaMask**에 SSAFY 체인(RPC/ChainID 31221) 수동 추가 후 GSC 토큰 임포트.
- 가입 절차: 별도 회원가입 없음. SSAFY 제공 RPC + 지급받은 계정/토큰 사용.

---

## 2) MetaMask (지갑 인증)

| 항목 | 내용 |
|---|---|
| 용도 | 회원 인증(EIP-191 `personal_sign` 서명 → 주소 복구) 및 온체인 트랜잭션 서명 |
| 백엔드 검증 | web3j-crypto 4.12.3으로 서명에서 주소 복구·검증 |
| 프론트 연동 | `frontend/src/features/wallet/` |
| 설정 | `WALLET_AUTH_DOMAIN` / `WALLET_AUTH_URI` / `WALLET_AUTH_CHAIN_ID`(31221) |
| 가입 | 사용자가 브라우저에 MetaMask 확장 설치 (무료) |

> 기존 소셜 OAuth 로그인은 **없음**. 지갑 서명이 로그인 수단을 대체한다.

---

## 3) 자체 호스팅 서비스 (외부 SaaS 아님, 참고용)

| 서비스 | 내용 |
|---|---|
| AI Scheduler | 자체 FastAPI (`http://ai:8000`, 내부). GPU 추천/런타임 예측. 외부 가입 불필요 |
| 오브젝트 스토리지 | 자체 `LocalObjectStorage` (백엔드가 파일 직접 보관 + 서명 URL). **S3/MinIO 미사용** |
| 관제 | Grafana + Loki + Alloy (`infra/observability`, `/grafana`). 자체 배포 |

---

## 4) TLS 인증서

| 항목 | 내용 |
|---|---|
| 발급 | Let's Encrypt (Certbot) |
| 적용 | Nginx 443 (`infra/nginx/default`) |
| 가입 | 무료, 서버에서 certbot으로 발급/자동 갱신 |

---

## 사용하지 않는 것 (명시)
- ❌ 소셜 로그인 (Google / Kakao / Naver / GitHub OAuth)
- ❌ Photon Cloud
- ❌ 외부 코드 컴파일 서비스 (Judge0 등)
- ❌ AWS S3 / GCP / 외부 클라우드 스토리지
