# AI Scheduler & GPU Worker 학습 정리

## 1. AI Scheduler 설계

GPU를 단순히 성능 순으로 배정하지 않고, **현재 작업을 실제로 수행할 수 있는 GPU인지 먼저 판단한 뒤 비용을 비교하는 방식**으로 설계했습니다.

- GPU 모델, VRAM, CUDA 사용 가능 여부, 현재 Worker 상태를 기준으로 실행 가능 여부 판단
- 공급자가 설정한 시간당 가격과 예상 학습 시간을 이용해 예상 비용 계산
- 가장 저렴한 GPU가 아니라, **실행 시간까지 고려했을 때 비용 효율이 좋은 GPU**를 선택하는 방향으로 설계
- 초기에는 Benchmark 데이터를 활용하고, 이후 실제 학습 기록이 쌓이면 Dataset 크기, Epoch, Batch Size, LoRA 설정 등을 이용해 학습 시간을 예측하는 방식으로 확장할 계획입니다.

---

## 2. GPU Worker PoC

외부 GPU PC가 Backend와 연결되고 실제 GPU 상태를 전달할 수 있는지 확인하기 위해 Python 기반 GPU Worker PoC를 진행했습니다.

- PyTorch와 NVML을 이용해 실제 NVIDIA GPU, VRAM, CUDA 사용 가능 여부 확인
- 실제 CUDA 연산을 수행해 GPU가 정상적으로 사용되는지 검증
- Worker가 Backend에 WebSocket으로 직접 연결하는 구조 설계
- 연결 직후 GPU 정보를 `REGISTER`로 전달하고, 이후 5초마다 `HEARTBEAT`를 보내 최신 GPU 상태를 갱신
- Worker의 연결 여부와 실제 작업 상태를 `ONLINE/OFFLINE`, `IDLE/BUSY`로 나누어 관리하도록 설계했습니다.

## 3. Worker 실행 환경

외부 PC마다 Python이나 CUDA 환경이 달라지는 문제를 줄이기 위해 **실제 학습은 고정된 Docker Image에서 실행하는 방향**으로 정리했습니다.

- LoRA 학습용 Docker Image를 미리 만들어 Docker Hub에 저장
- Worker가 Job을 받았을 때 필요한 Image가 없으면 자동으로 Pull
- Image에는 Python, PyTorch, CUDA Runtime, Transformers, PEFT, bitsandbytes와 학습 코드만 포함
- Base Model은 Image 안에 넣지 않고 Worker PC에 별도로 다운로드한 뒤 Cache하여 재사용

이렇게 하면 GPU 공급자가 학습 환경을 직접 설치할 필요가 없고, 어떤 Worker에서도 동일한 환경으로 학습을 실행할 수 있습니다.

---

## 4. 학습 데이터 전달 구조

학습 데이터나 결과 파일처럼 크기가 큰 데이터는 Backend를 거치지 않고 **IPFS 기반 P2P 방식으로 전달하는 구조**를 검토했습니다.

- Kubo를 이용해 사용자 PC와 GPU Worker를 IPFS Peer로 구성
- 사용자가 Dataset을 등록하면 CID를 생성하고 Backend에는 CID만 전달
- 선택된 Worker가 해당 CID를 이용해 Dataset을 직접 다운로드
- 학습이 끝난 후 생성된 LoRA Adapter 역시 IPFS에 등록하고 Result CID를 사용자에게 전달

현재 프로젝트에서는 공개 데이터와 비민감 데이터만 사용하도록 범위를 제한해 Public IPFS를 활용하는 방향으로 정리했습니다.

---

## 5. 전체 실행 흐름

```text
사용자
↓
Base Model + Dataset 등록
↓
Backend
↓
AI Scheduler가 GPU Worker 선택
↓
Worker가 Docker Hub에서 학습 Image 준비
↓
Base Model Cache 확인
↓
IPFS로 Dataset 다운로드
↓
Docker Container 실행
↓
GPU에서 LoRA / QLoRA 학습
↓
LoRA Adapter 생성
↓
IPFS로 결과 반환
```

이번 과정을 통해 **Scheduler는 어떤 GPU에서 실행할지를 결정하고, Worker는 실제 GPU 환경에서 작업을 실행하도록 역할을 나누는 구조**를 이해했습니다. 또한 GPU 연산뿐 아니라 Worker 상태 관리, 실행 환경 통일, 모델 캐싱, 대용량 데이터 전달까지 함께 고려해야 분산 GPU 시스템이 완성된다는 점을 학습했습니다.
